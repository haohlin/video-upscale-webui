# Architecture

The application has React/Vite browser client and FastAPI service. Startup builds Vite output; FastAPI serves it at `/` while its JSON/file API stays under `/api`. Tailscale Serve strips spoofed identity headers, injects `Tailscale-User-Login`, and proxies to the loopback-only backend. FastAPI compares that header case-insensitively after ASCII whitespace trimming with `VIDEO_UPSCALE_TAILSCALE_USER_LOGIN`; missing, wrong, and tagged identities receive 403. Only `/api/health` is exempt. State-changing requests also require the non-simple `X-Video-Upscale-Request: 1` header. Local processes are inside the trust boundary because they can connect directly and forge proxy headers; LAN and direct tailnet clients cannot reach the loopback listener. Funnel remains disabled.

Service owns inputs, bounded single-job queue, persistent SQLite history, media validation, and SeedVR2/FFmpeg process orchestration. A raw ASGI guard limits every upload body and admits one upload at a time before multipart parsing/spooling.

ComfyUI and SeedVR2 runtime assets remain outside Git. Runtime media layout is `inputs`, `staging`, and `results`; jobs and finished MP4 files persist until the operator deletes them in WebUI. Backend caps each job log but does not age-delete or count-prune results. Production profile is canonical `3b-safe`; 7B FP8 is explicit experimental probe only. Real-ESRGAN is deferred and not public API/UI preset.
